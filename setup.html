ATTENDANCE HELP

Sign in. Capture. Review.

For representatives

  1. Enter the private access code assigned by your administrator. The Google connection is already configured.
  2. Select the correct student and session. Inform the student that their photo and location will be recorded for attendance.
  3. Enable the live camera and location permissions, then capture the student with their face and event context visible. Submit promptly while the attendance session is open.
  4. A saved submission is pending until the administrator reviews it. Both sessions must be approved for a full day.

Your code covers your assigned section. The designated attendance assistant can record across all sections. Share a code only with its assigned student.

For the administrator

Use Event setup → Representatives & assistant to issue codes. Only one representative may be active for each section, plus one assistant for all sections. Revoke an existing assignment before replacing it. You retain control of evidence approval, settings, roster imports and access management.

Keep your administrator code private. The website source does not contain it. Lost representative codes must be revoked and recreated.

Check venue settings and perform a real phone capture pilot. GPS readings and timestamps are supporting evidence and need review. Use a documented exception process for poor signal or permission failures.

Connection or permission problems

Open this website directly in a phone browser over HTTPS. Allow camera and location for this website. If GPS is inaccurate, move to an open area and retry. If a code is rejected or a session is closed, contact the event administrator.

Records and evidence remain in private Google storage. Photo retention is managed by the administrator; the app does not automatically delete evidence.
